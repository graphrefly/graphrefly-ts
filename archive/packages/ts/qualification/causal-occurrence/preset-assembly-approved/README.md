## What changed and why

- Existing causal input adapters use the existing `partial: true` option so quiet outcome/admission lanes do not prevent finite authority progress. No protocol rule or message changed.
- Evidence directly depends on the actual material owner. A receipt waits for retained/no-publish material, and checks the exact request as well as code/input/policy/verifier domains. `included` records evidence presence, including a fail verdict; it does not grant permission.
- Each owner DATA frame replaces current policy availability. Empty or invalid frames cannot resurrect omitted permissions. Historical receipt identity and pending evidence are retained separately, with full `{kind,id}` identity and a 64-entry bound.
- Multiple DATA records remain ordered through the lane projections. Outcome retention and settlement remain in the original authority. Detaching all UI observers does not settle an obligation or release its material.
- The independent plain fixture is an initial finite comparison, not yet a complete all-domain reference. It handles first-outcome immutability, early exact outcomes across empty inbox frames, invalid DataResult rejection, and same-frame wrong-then-exact outcomes.
