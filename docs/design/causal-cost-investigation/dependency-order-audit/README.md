# Retained order and position audit

只读取 `135a13cd` 保留的有限对比数据。619 文件重新检查散列，96 个 block 的主指标
p50/p95 从原始样本重新计算，与原报告完全相同。没有 consumer 执行、新样本、删样本或新性能门槛。
唯一 owner 仍为 `graphrefly-ts:CAUSAL-PRESET-ASSEMBLY-TS`；本批是证据分析。

## 可以确定的现象

**偏差集中程度不同，不能用统一位置系数修正。** 构造的同代码控制如下；数值为同位置
B-copy/B 的两次重复比值中位数，位置 0/1 是进程内第一/第二个执行块。

| 控制区段 | 位置 | p95 比值 | p50 比值 |
| --- | --- | --- | --- |
| 开头 pair 0 | 0 | 0.8418 | 0.9783 |
| 开头 pair 0 | 1 | 0.9019 | 0.9525 |
| 末尾 pair 5 | 0 | 1.0166 | 1.0170 |
| 末尾 pair 5 | 1 | 0.9800 | 0.9830 |

开头控制的 p95 偏差在两次重复中方向一致；末尾两位置的重复方向均发生反转。
控制进程内第二块构造 p95 低于第一块是 6/8，并非 8/8：开头两个 V 进程第二块反而
高 2.48% 和 7.76%。第二块/第一块范围 0.7495–1.0776，同时混有模块 slot、进程内
先后与跨进程变化。该比较设计不足以把它们独立识别为因果效应。

**候选有值得保留的中心耗时改善线索，但尚无合格 p95 收益结论。**
主比较的构造 p50，16/16 个同位置单次比较 C/B <1；八个跨重复中位数为
0.8512–0.9094。p95 是 15/16 个单次比较 <1，八个跨重复中位数为 0.6645–1.0572，
其中一组重复方向相反。这些都是本次数据的描述，非独立的 16 次统计试验。
p50 原本有保留，但冻结方向判定使用 p95；不能事后改指标、调阈值或补偿控制来升级结果。

**个别慢尾确实抬高 p95，不能删掉。** 主比较 job 11 / 位置 0 / B 的构造：
p50 0.464292ms，p95 1.029792ms。五个连续十样本小段的中位数为
0.470291、0.474541、0.475938、0.469875、0.446854ms；最慢三个样本分别为
2.519500、1.523916、1.029792ms（原 index 36、37、43）。50 个 measured 样本的
nearest-rank p95 正好取第三大值。因此该块不是所有样本都慢一倍；但此事实不能判定
这些尾部来自 GC、JIT、调度，或证明多跑 warmup 就会消失。
job 7 的 p95 0.775625ms 同样高于 p50 0.451708ms，慢点也分散于测量段。

**负对照不支持统一修正。** inactive-1 release 的 p95 同代码控制在开头/末尾均有偏差，
范围 0.7531–1.3603；主比较八组中三组重复方向反转，16 次单次比值只有 7 次 <1。
release 仅数微秒量级，与 P2 构造不是同一时间尺度；不能把它的比值直接套到构造。

## 明确的未知与取舍

这是事后描述审计，没有 profiler、GC/JIT 对齐事件或 CPU/系统调度证据，不能把
时间模式归为某个 runtime 原因，更不能定位到 graph 节点内部。主机连续性通过只排除
触发既定检查的中断，不证明机器完全无噪声。

保留候选实现及原正确性证据，状态仍为“性能收益未确认”，本批不回滚也不扩大优化。
结束对这一批数据的重复重算：相同证据不能再分辨具体运行时原因。
若继续，应先审阅测量设计怎样区分中心耗时与慢尾、模块/顺序与实现差异，并预先固定
相应控制和停止条件；不能直接复制本方法多跑几次。本文件没有批准新方法或新采集。
原 frozen verdict **control-unstable/inconclusive** 不变，D169 和原 work 仍未完成。
