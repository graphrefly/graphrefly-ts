## Architecture delta

The same real Work Item and Agentic Memory solution composition remains. The raw
root topology now contains 311 nodes and 413 edges: two added nodes and four net
added edges, not another graph or a lifecycle simulation.

- `eval/provider/cost-settlements` validates admission-bound cost evidence before
  budget settlement. Its payload is private; its metadata/description is material-free.
- `eval/provider/start-spacing-readiness` retains campaign-wide 30/60/120/240-second
  pacing feedback. Three consecutive usable responses recover one step. Exact
  replay cannot reapply feedback; stale clock revisions cannot release a request.
  Exhausted requests still preserve a response-relative Retry-After lower bound.
- `eval/campaign/terminal` emits a coherent completed/stopped result. Incomplete
  budget stops have no finding. Already-admitted source tools drain even if their
  original five-source barrier can no longer fill. Pending tool admissions remain
  explicit in the activity state; zero active effects alone is insufficient.
- Evidence v27 persists a stopped terminal separately from a complete scientific
  finding. A cleanup failure is a fault, not an indefinitely pending normal stop.
  Finishing billing after the admission cutoff does not erase a completed finding.
- A pre-existing adapter-fault classification defect was found during QA: an
  `executor-failed` outcome carrying an HTTP 429 could be reclassified as a retry.
  Canonical admission now preserves the fault while retaining independent cost
  evidence. The regression traverses the Graph and verifies fail-closed source
  handling, settlement and absence of a retry effect, not just adapter output.

No new operator `partial` override, ordinary `RESOLVED` emission, domain-ordering
timer or caller-owned domain queue was added.
